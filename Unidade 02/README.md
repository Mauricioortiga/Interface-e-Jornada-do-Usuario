**Nesta unidade 02, iremos aprender:**

1. Transformar conceitos abstratos em experiências tangíveis, desde rascunhos iniciais até simulações interativas sofisticadas.

2. Testar e ajustar interfaces com usuários reais através de testes de conceito estruturados, antes de escrever uma única linha de código.

3. Redução de riscos e custos: Evita o fracasso de projetos digitais ao não investir recursos significativos em ideias erradas ou não testadas.

4. Permitir explorar alternativas de design e obter feedback crucial antes da implementação final.

5. Garante o desenvolvimento de interfaces que verdadeiramente atendam às necessidades reais dos usuários.

**Objetivos:**

Compreender os diferentes tipos de protótipos e seus níveis de fidelidade, sabendo quando aplicar cada abordagem;

Dominar ferramentas profissionais de prototipagem para criar wireframes e protótipos interativos;

Planejar e conduzir testes de conceito que gerem insights acionáveis para melhorar suas interfaces;

Integrar princípios fundamentais de acessibilidade desde as fases iniciais de prototipagem;

Estruturar processos de feedback iterativo que otimizem continuamente suas soluções de design.
