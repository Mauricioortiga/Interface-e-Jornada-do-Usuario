**Nesta unidade 04, iremos aprender:**

**Avaliação Sistemática de Interfaces:** Como aplicar métodos científicos de avaliação para descobrir problemas invisíveis nas telas, substituindo suposições e opiniões por dados concretos de comportamento.

**Testes de Usabilidade na Prática:** Como planejar e conduzir testes com usuários reais para gerar insights valiosos e acionáveis para o projeto.

**Documentação e Comunicação de Insights:** Técnicas para registrar as descobertas dos testes e comunicar os problemas de usabilidade de forma convincente para a equipe ou clientes.

**Processo de Design Iterativo:** Como adotar a mentalidade de testar, analisar e refinar continuamente a interface, transformando o feedback dos usuários em melhorias práticas de design.

**Validação e Mitigação de Riscos:** Como validar decisões de design com confiança para corrigir falhas de usabilidade antes que elas se tornem retrabalhos caros no desenvolvimento.

**Objetivos:**

- Aplicar diferentes métodos de avaliação de interfaces conforme o contexto e os objetivos do projeto.

- Planejar e executar testes de usabilidade presenciais e remotos com rigor metodológico.

- Analisar resultados de avaliações identificando padrões, severidade de problemas e oportunidades de melhoria.

- Documentar descobertas e comunicar recomendações de design para diferentes públicos.

- Integrar avaliação e testes em processos iterativos de desenvolvimento de interfaces.
